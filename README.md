# SmartDecision

This repository contains a full demo web app for SmartDecision — a business decision support system built with React + Vite + TypeScript + Tailwind CSS.

## Tính năng chính
- Dashboard tổng quan với KPI chính
- Quản lý dữ liệu kinh doanh
- Phân tích xu hướng
- KPI & mục tiêu
- Cảnh báo bất thường
- Dự báo doanh thu
- What-if simulation
- So sánh phương án
- Đề xuất hành động
- Báo cáo & lịch sử quyết định
- Demo mode with localStorage and Supabase-ready configuration
